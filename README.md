# Dis-Enchanting-Table for 1.20.1






- A block: Dis-Enchanting Table
  - Inventory: 2 Input Slots (Enchanted Item/Book + Book) + 1 Output Slot (Enchanted Book)
  - Logic: Remove all enchants from regular items, or one enchantment from enchanted book

- An item: a BlockItem to place the table

- A creative mode tab: to display our item
